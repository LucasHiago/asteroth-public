# Contos do mundo de Asteroth

Aqui moram histórias curtas ambientadas no mundo. Cada conto é independente — pode ser lido sozinho — mas todos se passam no mesmo planeta, sob o mesmo sol, sob as duas luas.

> *Em construção.*

A intenção é que essa pasta cresça com o tempo, e que dela nasçam livros no futuro.

## Como ler

A ordem cronológica do mundo (quando o conto se passa em relação à linha do tempo de Asteroth) será marcada no início de cada arquivo. Sem isso, leia em qualquer ordem.

## Convenção interna

- Um conto por arquivo.
- Nome do arquivo: `NN-titulo-em-snake-case.md`, onde `NN` é a ordem de publicação (não cronológica).
- Cabeçalho do arquivo:

  ```markdown
  # Título

  > *Local · Ano · Estação (in-world).*

  ---

  Texto do conto.
  ```
